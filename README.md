# BART Partition Point Estimator

This project explores methods for extracting a single interpretable partition of covariate space from a fitted Bayesian additive regression trees (BART) model. The goal is to describe subgroups through simple covariate rules that summarize information learned by the ensemble.

Possible approaches include summarizing posterior tree structure, selecting partitions through Bayesian decision theory, and constructing partitions based on predicted outcomes. These are starting directions for methodological development.

## Literature and sketches

The literature search is open-ended. Relevant work may come from Bayesian partition estimation, subgroup discovery, tree ensembles, predictive projection, model interpretation, and related areas. Additional references and approaches can be incorporated as the project develops.

Individual Markdown files contain short sketches inspired by relevant papers, including the core idea, essential equations, and algorithm steps. Each distinguishes the published method from proposed adaptations for BART partition estimation.

These notes are intended to support collaboration and the development of new ideas.
