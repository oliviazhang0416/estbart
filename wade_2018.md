# Wade and Ghahramani (2018): A partition summary using VI loss

**Reference:** Wade, S., and Ghahramani, Z. (2018). *Bayesian Cluster Analysis: Point Estimation and Credible Balls (with Discussion)*. **Bayesian Analysis**, 13(2), 559–626. [Paper](https://doi.org/10.1214/17-BA1073) · [Accessible manuscript](https://arxiv.org/abs/1505.03339).

**Published idea.** Select a representative partition by minimizing posterior expected variation-of-information (VI) loss.

## Proposed BART sketch

Fix reference covariates $x_1,\ldots,x_n$. Each saved component tree $T_h^{(b)}$ induces a partition $\pi^{(b,h)}$ of these observations. This defines a distribution of partitions by averaging over posterior draws and uniformly over component trees.

For two partitions $\pi$ and $\pi'$, define

$$
\operatorname{VI}(\pi,\pi')=H(\pi)+H(\pi')-2I(\pi,\pi').
$$

Here, $H$ is entropy and $I$ is mutual information. If $p_k$ and $q_l$ are the fractions of observations in their respective groups, and $r_{kl}$ is the fraction in the intersection of groups $k$ and $l$, then

$$
H(\pi)=-\sum_k p_k\log_2 p_k,
\qquad
I(\pi,\pi')=\sum_{k,l:r_{kl}>0}r_{kl}\log_2\frac{r_{kl}}{p_kq_l}.
$$

VI equals zero for identical partitions, irrespective of group labels.

For a candidate set $\mathcal C$ of trees, select

$$
\widehat T\in\arg\min_{T\in\mathcal C}
\frac{1}{BH}\sum_{b=1}^{B}\sum_{h=1}^{H}
\operatorname{VI}\left(\pi(T),\pi^{(b,h)}\right).
$$

This sketch uses the sampled partitions directly to calculate the Monte Carlo average VI loss. The simplest choice for $\mathcal C$ is the saved component trees.

## Algorithm sketch

1. Obtain the group assignments induced by each saved component tree.
2. For each candidate tree, tabulate its group overlaps with each saved partition.
3. Calculate VI for each comparison and average over $(b,h)$.
4. Return a minimizing tree and its leaf rules.
