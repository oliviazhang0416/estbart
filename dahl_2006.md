# Dahl (2006): Representative BART partition

**Reference:** Dahl, D. B. (2006). *Model-Based Clustering for Expression Data via a Dirichlet Process Mixture Model*. [Paper](https://dahl.byu.edu/papers/dahl-2006.pdf).

**Published idea.** Select a sampled partition whose pairwise co-clustering matrix is closest to the posterior average co-clustering matrix.

## Proposed BART sketch

Use reference covariates $x_1,\ldots,x_n$, such as the observed covariates. Let $T_h^{(b)}$ be component tree $h=1,\ldots,H$ in saved posterior draw $b=1,\ldots,B$. Write $\ell_T(i)$ for the leaf containing $x_i$ in tree $T$.

Record whether each pair shares a leaf:

$$
A_{ij}(T)=\mathbf 1\{\ell_T(i)=\ell_T(j)\}.
$$

Average over posterior draws and component trees:

$$
P_{ij}=\frac{1}{BH}\sum_{b=1}^{B}\sum_{h=1}^{H}A_{ij}(T_h^{(b)}).
$$

This estimates the same-leaf probability for a component tree selected uniformly from a posterior ensemble draw.

Select a representative tree from the saved trees:

$$
\widehat T\in\arg\min_{T\in\mathcal T_{\mathrm{saved}}}
\sum_{i<j}\left[A_{ij}(T)-P_{ij}\right]^2.
$$

## Algorithm sketch

1. Assign each reference observation to a leaf in every saved component tree.
2. Calculate the average same-leaf matrix $P$.
3. Calculate the squared-distance score for each saved tree.
4. Return a minimizing tree, its leaf rules, and the resulting group assignments.

**Output:** One sampled BART tree defining a partition of covariate space. This is the direct adaptation sketched in Aim 3.
